OPTION 2: USE REAL DATABASE (Production - 15 minutes)
================================================================================

STEP 1: Create Supabase Database

1. Go to: https://app.supabase.com
2. Sign up (if new user)
3. Click "New Project"
4. Fill in:
   - Project name: clairvoyant
   - Password: [Create strong password - SAVE THIS!]
   - Region: ap-south-1 (Mumbai) ← IMPORTANT FOR INDIA
   - Plan: Free
5. Click "Create new project"
6. Wait 2-5 minutes for database to initialize
7. You'll see: "Your project is ready"

STEP 2: Get Connection String

1. In Supabase dashboard, click "Settings" (bottom left)
2. Click "Database"
3. You'll see "Connection string" section
4. Make sure it's in "URI" format
5. Copy the string that looks like:
   postgresql://postgres:PASSWORD@abc123xyz.supabase.co:5432/postgres
6. SAVE this string

STEP 3: Initialize Database

1. In Supabase, click "SQL Editor" (left sidebar)
2. Click "+ New query"
3. Open DATABASE_SCHEMA.sql file
4. Copy ALL the SQL code
5. Paste into Supabase SQL Editor
6. Click "Run" button
7. Wait for: "✓ Query Successful"

STEP 4: Configure Local Environment

1. Open folder: clairvoyant (where you put files)
2. Find file: .env.example
3. Right-click → "Rename"
4. Change name to: .env.local
5. Open .env.local in notepad
6. Find this line:
   DATABASE_URL=postgresql://postgres:YOUR_PASSWORD@YOUR_HOST.supabase.co:5432/postgres
7. Replace with YOUR connection string from Step 2
8. Save file

STEP 5: Install & Run

$ npm install
$ npm run dev

STEP 6: Open in browser

Go to: http://localhost:3000
Login: admin@clairvoyant.com / demo123

✅ NOW YOUR APP IS CONNECTED TO REAL DATABASE!

Try:
├─ Create invoice
├─ Refresh page (data persists!)
└─ Go to Supabase → see data in table!

================================================================================
TROUBLESHOOTING
================================================================================

Q: "npm: command not found"
A: Node.js not installed. Go to https://nodejs.org/ and install

Q: "PORT 3000 already in use"
A: Another app is using port 3000
   Run: npm run dev -- -p 3001
   Then go to: http://localhost:3001

Q: "DATABASE_URL not found"
A: 1. Check .env.local exists
   2. Check DATABASE_URL line is there
   3. Restart: npm run dev

Q: "Connection refused"
A: 1. Check your Supabase project is active
   2. Check DATABASE_URL is correct
   3. Wait 5 minutes if project just created

Q: "Tables don't exist"
A: 1. Go to Supabase SQL Editor
   2. Create new query
   3. Open DATABASE_SCHEMA.sql
   4. Copy & paste SQL
   5. Click "Run"

Q: "Login doesn't work"
A: For demo (in-memory): Use admin@clairvoyant.com / demo123
   For real database: Need to implement auth (see SETUP_GUIDE.md)
